\chapter{Problemas de vibração livre com o Método dos Elementos Virtuais}

\indent Neste capítulo, são analisados cinco problemas de vibração livre no estado plano:

    \begin{itemize}
        \item Uma viga em balanço no estado plano de tensões;
        \item uma chapa engastada no estado plano de tensões;
        \item uma chapa engastada com furo circular no centro no estado plano de tensões;
        \item uma barragem de terra no estado plano de deformações, e
        \item uma parede estrutural de 4 pavimentos no estado plano de tensões. 
    \end{itemize}

\indent Para estudos de resultados será utilizado o erro relativo calculado por:
\begin{equation}
    e = \big| \frac{\omega_{ref} - \tilde{\omega}}{\omega_{ref}} \big|,
\end{equation}
com $\omega_{ref}$ sendo a frequência de referência e $\tilde{\omega}$ a frequência calculados para cada modo de vibração.\\
\indent Neste trabalho a formulação do MEV e outras rotinas computacionais são implementadas com um solver programado em Modern Fortran
e o Gnuplot para visualização de resultados. Gráficos e tabelas comparativas são feitas com auxílio do LibreOffice Calc. As malhas são gerados com o uso do software AutoCAD.\\
\indent Como os elementos virtuais podem possuir arestas com 180° entre si, podem existir malhas com a mesma quantidade de elementos, mas com diferentes quantidades de nós. Assim, adota-se o seguinte padrão de nomenclatura para as malhas utilizadas daqui em diante neste trabalho: $$XX\#\#\#N\#\#\#k\#$$. 

    \begin{itemize}
        \item X - Letras
        \item \# - Números
    \end{itemize}
    
\indent O primeiro conjunto de letras corresponde às iniciais do problema. O primeiro conjunto de números representa a quantidade de elementos na malha. N\#\#\# é a quantidade de nós. Exemplo: PF32N74 $\rightarrow$ Placa com furo de 32 elementos e 74 nós. \\
\indent Todos os problemas aqui tratados são de natureza vetorial, assim a quantidade de graus de liberdade por elemento equivale a duas vezes a quantidade de nós. Em aproximações de segunda ordem, haverá dois graus de liberdade internos adicionais aos dos nós relativos a vetorização dos momentos internos para $k=2$. 

\section{Viga em balanço}

\indent O primeiro problema abordado no trabalho é uma viga em balanço com bordo esquerdo engastado, (Figura~\ref{fig:5.1}). A viga possui 10 metros de comprimento e 1 metro de altura, como espessura de 0,5 metros. As propriedades do material são: Módulo de elasticidade $E = 1,0 N/m²$, massa específica $\rho = 1,0 kg/m³$ e coeficiente de Poisson $\nu = 0,3$.

\indent O problema apresentado possui solução conhecida. Para as formas axiais, a solução é:
\begin{equation}
    \omega_{n,axial} = \frac{2n - 1}{4 L} \sqrt{\frac{E}{\rho}},
\end{equation}
para formas de flexão:
\begin{equation}
    \omega_{n,flexão} = (\beta_n L^2) \sqrt{\frac {E I}{\rho A L^4}}.
\end{equation}
A determinação das formas para comparação com os resultados numéricos é dependente das deformadas de cada modo. Numericamente:

\indent O objetivo desse problema é validar os resultados numéricos do método dos elementos virtuais com o refino-h, refino-p e refino-hp para diferentes técnicas de estabilização e assim comparar os resultados obtidos.\\
\indent As técnicas de estabilização utilizadas para esse problema são:
\begin{enumerate}[label=\Roman*.]
    \item $\tau_K = \max_i(K^C_{ii})$ 
    \item $\tau_K = \max(2\mu,\lambda)$ 
    \item $\tau_K = \alpha_0\,\mathrm{tr}(K^C)$ 
    \item $\Lambda_K = \mathrm{diag}\bigl(|K^C_{ii}|\bigr)$ 
    \item $\Lambda_K = \max\!\Bigl(\mathrm{diag}\bigl(|K^C_{ii}|\bigr),\; \alpha_0\,\tfrac{\mathrm{tr}(\mathbb{C})}{n_C}\Bigr)$.
\end{enumerate}

\indent Adota-se para a variável $\alpha_0$ o valor de $1/2$ para a estabilização $III$; e $1/3$ para a estabilização $IV$ conforme se recomenda na literatura. A matriz de massa é estabilizada utilizando: $$\tau_m = \big|\Omega_v \big| \rho.$$\\

\section{Parede estrutural}

\indent O quarto problema abordado consiste em uma parede estrutural no estado plano de tensões (Figura~\ref{fig:5.23}). A parede possui módulo de elasticidade $E = 1{,}0 \times 10^{4}\,\text{N/m}^{2}$, coeficiente de Poisson $\nu = 0{,}2$, massa específica $\rho = 1\,\text{kg/m}^{3}$ e espessura $d = 1\,\text{m}$. 
O problema foi proposto em \citet{nguyenthanh2010alternative} como ``benchmark'' para uma formulação alternativa do Método dos Elementos Finitos $\alpha$ (A~$\alpha$~FEM). Os autores comparam a solução com elementos finitos triangulares padrão, uma solução via software ABAQUS, o Método dos Elementos de Contorno e o método sem malha de Petrov-Galerkin local.
